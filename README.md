## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/WispXeno.git`
2. `cd WispXeno`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure WispXeno, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
